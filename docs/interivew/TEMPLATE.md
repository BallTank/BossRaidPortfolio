# [Interview] 주제명

이 문서는 버그 수정, 구조 개선, 성능 문제, 트러블슈팅 사례를
**면접 답변 톤**으로 정리하기 위한 템플릿이다.

작성 원칙:

* 한 문서에는 사례 1개만 다룬다.
* `문제 정의 -> 가설 -> 추적 과정 -> 실제 원인 -> 수정 -> 검증 -> 면접 답변` 순서를 유지한다.
* 답변은 `무엇을 봤는가`, `왜 그렇게 의심했는가`, `어떻게 좁혔는가`가 드러나야 한다.
* 처음 생각과 최종 결론이 달랐다면, 그 변화가 보이게 적는다.
* 결과만 적지 말고, 판단 과정도 남긴다.

---

## 1. 한 줄 요약

* 이 문제는 무엇이었고, 최종적으로 무엇이 원인이었는가.

예시:

* remote player의 locomotion만 Host에서 보이지 않았고, 원인은 Host-side locomotion authority path에서 animator sync가 빠져 있던 것이었다.
