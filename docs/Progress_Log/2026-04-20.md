## 기술적 고려
### 무엇을 발견했는가
* 기존 `SwordSlashSpawner.Update()` 흐름은 `currentVelocity > velocityThreshold`이면 slash를 스폰했다.
* Easy flow: `move input -> sword tip moves fast -> velocity threshold pass -> slash spawned`.

### 무엇을 수정했는가
* `Awake()`에서 `GetComponentInParent<PlayerController>()`로 controller를 자동 바인딩했다.
* `IsAttackStateActive()`를 추가해 `playerController.StateMachine.CurrentState == playerController.AttackState`일 때만 스폰 로직이 실행되게 했다.
* 비공격 구간 early return 전에 `_lastPosition`을 현재 위치로 갱신했다.

### 왜 그렇게 판단했는가
* 요구사항은 "공격할 때만 VFX"이므로, 속도 임계값 자체를 조정하는 것보다 상태 게이트가 root cause를 직접 제거한다.
* `AttackState`는 이미 프로젝트의 공격 진실값(source-of-truth)이므로, 새 입력 시스템을 만들지 않고 현재 구조를 재사용하는 것이 최소 변경이다.
