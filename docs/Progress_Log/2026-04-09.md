#### 왜 그렇게 판단했는가
* AoE bug의 핵심은 spawned effect 부재가 아니라 boss body animation phase 정보가 snapshot에 없다는 점이므로, effect event가 아니라 authoritative state contract를 확장하는 편이 더 정확했다.
* client가 AoE 전체를 단일 attack id로만 보면 takeoff 이후 semantic transition을 알 수 없으므로, visual phase를 explicit field로 보내는 방식이 가장 단순하고 회귀 범위도 작다.
